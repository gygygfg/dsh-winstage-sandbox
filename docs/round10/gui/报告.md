```yaml
- id: winstage-sandbox   # name 必须重述；config 是整体替换
  name: "dsh-winstage-sandbox"
  config: { enabled: true, workspaceRoot: C:\…\dsh-winstage-sandbox, probeOnStart: true }
- id: winstage-fs
  name: "dsh-winstage-sandbox/fs"
  config: { cwd: C:\…\dsh-winstage-sandbox, workspaceRoot: C:\…\dsh-winstage-sandbox }
- id: winstage-shell
  name: "dsh-winstage-sandbox/shell"
  config: { workspaceRoot: C:\…\dsh-winstage-sandbox }
```

**环境变量**：`WINSTAGE_SHELL=1`（越过 profile 的 `enabled: false`）、`DSH_SESSION_ID=`（清空，避免挂到 Lead 会话）、`WINSTAGE_STAGE_ROOT=…`（避开 3080 宿主占着的 `%LOCALAPPDATA%\Temp\winstage-stage\dsh-host` 哨兵，见配方 §5.1）。
