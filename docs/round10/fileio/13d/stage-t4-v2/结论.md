## 6. 口径与陷阱（供终版报告/纪律清单）

1. **`class=4` 探针不可作判据**：`nqifbn-probe.exe` 的 OA 合法（`InitializeObjectAttributes`+`\??\` 绝对名+正确 `Length`），但 `FileInformationClass=4` **被该 API 拒绝**——**无 shim** 直跑 `kernel32.dll` 也返回 `0xC000000D` ⇒ 规格 §7 / 收束 §5.1 的"裸路径串调用"归因**误**。判据只用 `class=77`。
2. **`0xC0000034` 与 whiteout 同码** ⇒ 必须读 `mapped=<whiteout> staged=0` 才能区分。
3. **不要用 `staged1Win32Form` 误读**：`path=` 是剥前缀后的逻辑名，v2 下**全部** `staged=1` 行的 `path=` 都是 Win32 形态；"实际传入串"看 `nt=`。
4. **冻结件瑕疵（诚实披露）**：`driver.cmd` 的小写盘符子探针误写为小写化的 `%WS%`（应为 `%TARGET%`）⇒ 探的是 `<ws>` 目录；且 `class=4` 不可判 ⇒ 该子探针既错又无用。为保 v1↔v2 逐字可比**未改**；小写盘符结论仍按静态分析：`mapped=` 可能显示小写，但 NTFS 大小写不敏感 ⇒ 只看 `staged=1` 且 `status=0x0`。
5. **`C:\` 覆盖**：`dir-ab-driver.cmd` 里 `"C:\"` 尾部反斜杠转义闭合引号 ⇒ `dirab-01` 未落盘（`result:false` 已按无效剔除）；由 `dir-root-driver.cmd` 用 `C:\.` 补齐（pid 7176，同源 ✅）。
6. **候选不重建**（整件 sha 含 `.rdata`/buildid 时间戳）；判"同代码"用 `.text`。
