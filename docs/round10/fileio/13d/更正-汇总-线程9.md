- **权威回滚（二选一，均须复核回 `60ACEC39…`）**

### 1.2 【产品缺陷根因】规格 §3 骨架 `un.Buffer = mapped;` 是**错的** ⇒ 造成 v1 候选"脆性绿"
- 规格骨架把 `ws_stat_resolve` 返回的 `mapped` **直接**交给 NT 级 API。但 `mapped` 是 **Win32 形态**（`C:\…`，因为 `ws_GetFileAttributesW` 用它调 Win32 API），而 `NtQueryInformationByName` 的 `ObjectName` 必须是 **NT 对象路径**（`\??\C:\…`；`RootDirectory=NULL` 时裸 `C:\…` 被对象管理器当作根下的 `\C:\…`）。
- **无车道、无 shim 的直接实验定案**（`exe`，`docs\round10\verify\evidence\t5\T5-4-rootcause-nt-form-proof.txt`）：
  ```
  NT    form="\??\C:\Windows\System32\kernel32.dll" status=0x00000000
  WIN32 form="C:\Windows\System32\kernel32.dll"     status=0xC000003B   (STATUS_OBJECT_PATH_SYNTAX_BAD)
  ```
  并由 `line-a-fix` 以**真实深路径文件**复证（Win32 被拒 / 转 NT 后 `0x0`）。
- 后果：v1 候选（`out-13d-count14`）的**覆盖层映射调用 67/67（T5 轮 87/87）全为 `0xC000003B`、成功 0 条**；`statSync` 表面变绿是 **libuv 在 `STATUS_OBJECT_PATH_SYNTAX_BAD` 上回退 `CreateFileW`**（该路径本就 overlay 感知）。⇒ 记 **fragile-green（脆性绿）**，**未满足规格 §4③**（要求 `status` 转为**覆盖层成功**）。
- 修正：**D98** 在换名分支构造 NT 形态（`\??\C:\…`；真 UNC ⇒ `\??\UNC\…`；已是 `\??\` 不重复加；**其它形态一律不换名、原样透传**），`Length/MaximumLength` 按 NT 串重算，日志增打 `nt=`。
- 同文件先例（既有正确写法）：`ws_NtOpenFile`（`ws_file.c:1173`）——`\??\` 只用于自己的判断，**交回真实 API 时保持 NT 原名**。

### 1.3 【规格 §6 顺序】不是"先绝对化再解析"，而是**先剥 NT 前缀、再绝对化**
- `line-a-fix` 实测：`GetFullPathNameW("\??\C:\x")` = **`C:\??\C:\x`**（它**不剥** `\??\`）⇒ 照 §3 骨架"先 `GetFullPathNameW`"对合法 NT 形态**仍是 no-op**。
- 正确次序：**先**把 `\??\C:\…` / `\??\UNC\…` 剥成 Win32 形态，**再**用 CWD 绝对化，**再**交 `ws_stat_resolve`。

### 1.4 【误归因】`nqifbn-probe.exe` 的 `0xC000000D` 不是"裸路径串调用"造成的
- 规格 §7 与 `线A-收束.md` §5.1 曾把该 `STATUS_INVALID_PARAMETER` 归因于"裸路径串调用该 API"。**实测更正**：该探针的 `OBJECT_ATTRIBUTES` **是合法的**（`InitializeObjectAttributes` + `\??\` 绝对名 + 正确 `Length`）；`0xC000000D` 来自 **`FileInformationClass=4` 被该 API 拒绝**。
- 后果：**该探针无区分力**（v1/v2/修前均得 `0xC000000D`）⇒ **验收判据只能用 `class=77` 的真实调用行**。
- 另两条已采纳的补充：`0xC0000034` 与 **whiteout 分支同码** ⇒ 必须读 `mapped=<whiteout> staged=0` 才能区分；`0xC000003A`(PATH_NOT_FOUND) 与 `0xC0000034`(NAME_NOT_FOUND) 的差异由**真实盘祖先目录是否存在**解释（同族差异，非口径冲突）。

### 1.5 【归因被反证】D87 的"`existsSync` post-call 返回值被丢弃"**不成立**（纪律部分仍成立）
- `D87` 原结论：`GetFileAttributesW` 成功返回 `attrs=0x20`，调用方仍见 `false` ⇒ post-call 丢弃。
- **v2 实测反证**：v2 下 `existsSync=true`，且**同 pid 序列里夹具 `NQIFBN(nt=… status=0x0)` 成功后该夹具再无 `CreateFileW`** ⇒ 成功**经由 NQIFBN 本身**；而 b13（`0xC0000034`）/ v1（`0xC000003B`）下 `exists=false`。两轮里决定 D87 结论的那条 `ATTRDBG-W` **逐字同形**（`rc=0 staged=1 attrs=0x20 err=203`）⇒ 决定 `exists` 的**不是** W 的返回值，而是 **stat 那条路**（Node `existsSync` = `statSync` 包 try/catch）。
- **仍须保留**：D87 的"**判据不能用 `err` 残留**"（`GetFileAttributesW` 成功**不清** `LastError`，`err=203` 是陈旧值）——被推翻的只是**归因**，不是这条纪律。
- 线 B 因此**不立单独候选**，结案为"前提证伪 + 回归项"，见 `线B-结案.md`。

### 1.6 【不入库保证】`.gitignore` 的 `docs/round10/*/evidence/` **不跨目录分隔符**
- 实测 `git check-ignore -v docs/round10/fileio/13d/stage-nqifbn/evidence/shim.log` 命中的是 `*.log`（第 95 行），**只有日志被偶然挡住**；同目录 `.txt`/`.json`/`.jsonl` 会被 `git add` 扫进版本库。
- 已在 `.gitignore` 增加 `docs/round10/**/evidence/` 与 `docs/round10/**/evidence-archive/`（覆盖任意深度）。`.gitignore` **不在** 115 条封印面内（已核），故此项不破坏 `baseline-sha256 --check`。

| # | 纪律 | 来源/理由 |

## 9.1 D-FILE-5：第一版候选（D99）被载体缺陷击落，根因是**无界重入**
- `D99`（NQAF/NQFAF overlay 感知）在车道上使注入载体 `powershell.EXE` **自身初始化期**以 **`STATUS_STACK_OVERFLOW (0xC00000FD)` 死亡 3/3**，executor fail-closed 回落 T1（≈345 ms）；同入口换 `count15` = `TS/shim`、2,864 ms。
- **因果切分（单变量 A/B，互为替代）**：`dbg-guard`（**只加**重入守卫，栈画像不变）⇒ **TS/shim、无 `0xC00000FD`**；`dbg-smallframe`（**只把缓冲移出栈**，无守卫）⇒ **T1 + `0xC00000FD`**。⇒ **根因 = 重入；~49 KB/调用的栈占用是"非因果伴随"**（B 已证否其充分性）。
- **机制链**：外部 NQAF(逻辑名) → 包装 → `ws_attrbyname_overlay` → `ws_stat_resolve` → **provider 探针**（`dp_file_resolve`（`ws_stage.c:131-168`）→ `ws_marker_exists`/`ws_exists`（`:146`/`:150`）→ `GetFileAttributesW`（`:99-124`））**派生并查询覆盖层候选路径** → 真实 API 经我们已挂钩的 `NtQueryAttributesFile` **以覆盖层路径重入包装** ⇒ 层层派生。实测：崩轮 **89%** 的入参 `path=` 已是派生形态；守卫轮 **8,019 次**被拒于入口；相邻 NQAF 的 `seq` 间隔 **median = 1**。
- **必须记住的错误归因**：触发面**不是** `__PSScriptPolicyTest_*`（0 命中）；锁定探针环是**另一条**已证实闭环（由 `demo-lockdown-caller` 演示）。v2 守卫对两条都有效。

- **守卫的权衡（如实）**：**并非"零语义变化"** —— 嵌套按名查询退化为**透传**（= 修复前行为）；顶层（未置位）行为不变。已静态核"**无早退漏清位**"（所有出口为 `break`，循环外唯一清位点；嵌套重入在入口返回、不触碰标志）。
