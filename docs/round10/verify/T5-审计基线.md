## 3. 判据口径（写入结论件时强制执行）

1. **恒等性判据 = 整件 sha256 + 字节数 + mtime**（D-R9 §2：整件 sha 只用于"同一文件两个时刻"）；
2. **"是否同一份代码"判据 = `.text` 分段摘要**（不跨构建断整件哈希相等）；
3. 一切读数的 join **按 `pid`**（不按 `canonical=` 之类"只有部分路径才写"的字段）；
4. 判据用 `status`/`rc`/`attrs`/`staged`，**不用 `LastError` 残留**（D88）；
5. **0/阴性结论必须附同 run 活性反证**，否则只记 `inconclusive`；
6. 脚本外层退出码 ≠ 内部判据（D-R9 §6 尾）。
