## 3. 静态审计

### D101（`ws_GetProcAddress` 名字路径）
- 新增 `ws_name_identity(name, real)`：`!name || !real || !g_orig.GetProcAddress ⇒ NULL`（**真实解析器未捕获 ⇒ 不换**）→ `wrapper = ws_hook_resolve(name)`；**未覆盖名 ⇒ NULL** → 对 `{kernelbase, kernel32, advapi32, ntdll}` 逐模块 `g_orig.GetProcAddress(order[k], name) == real` 做**地址同一性**；**任一命中 ⇒ 换**；**全不中 ⇒ NULL ⇒ 调用方保留 `real`**。
- 调用点：名字路径由"按名匹配"改为 `ws_wrapper_for_real(real)`（纯内存）→ 未中再 `ws_name_identity`（最多 4 次**真实**解析）。
- **递归 = 未引入**：新增路径唯一对外调用是 **`g_orig.GetProcAddress`（捕获的真实 API）**；其余为纯内存（`ws_hook_resolve`/比较）。**该补丁没有**误用直名 `GetProcAddress`（已逐行核对）。
- **未新增 fail-closed**：入口 `!g_orig.GetProcAddress ⇒ return NULL` 为**既有**行；其余一切失败回落 `real`。
- **语义**：外部模块的**同名异址**导出 ⇒ `real` ≠ 四个系统模块任一地址（地址唯一属于一个模块）⇒ 返回 **真身**（O1 缺陷被闭合）；系统模块变体（kernel32/advapi32/kernelbase）⇒ 命中 ⇒ 仍返回包装（**覆盖尽量不丢**，其"零丢失"由 ③ 的覆盖矩阵行为验证，见 §5）。

### D101b（`ws_LdrGetProcedureAddress` 名字路径，同一机制的第二个入口）
- `if (buf && len && len < 128)` 才进入；`char namez[128]; memcpy(namez, buf, len); namez[len] = 0;` ⇒ **有界拷贝，无越界**（`len ≤ 127` ⇒ `namez[127]` 恰为终止符）。
- 用 `ws_name_identity(namez, *ProcedureAddress)`（= 加载器刚为调用方模块解析出的**真实地址**）做同一性判定；**未中 ⇒ 保留真实地址**。
- **递归 = 未引入**（同上，仅 `g_orig.GetProcAddress`）；**未新增 fail-closed**。
- **观察（非阻塞）**：`len ≥ 128` 的名字**不再替换**（"不猜测"边界）——系统 API 名远短于此，实际影响为零；已记录。
