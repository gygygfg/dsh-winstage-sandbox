### 3d. `D98` 补丁**静态审计**（我方独立读补丁 + 源码，不引用作者自评）

**NT 形态转换规则（三条，其余一律不换名）**：① 已是 `\??\` 且非空 ⇒ 原样用（**不重复加前缀**）；② 真 UNC `\\server\share…`（第 3 字符既非 `?` 也非 `.`）⇒ `\??\UNC\` + 余部；③ 盘符绝对 `X:\…`（大小写皆可）⇒ `\??\` + 原名。**其它一切**（`\\?\…`、`\\.\…`、`\Device\…`、`\\?\GLOBALROOT…`、单 `\` 开头、相对名）⇒ `ws_ntOk=0` ⇒ **不换名、原样透传**（`nt=<none>`）——**方向正确且 fail-safe**。

**零 path I/O**：与 §附录 `T5-静态审计-D96.md` §4 同结论（直接零 I/O；`ws_is_lockdown_probe` 名族的**一次只读**真实属性查询为既有边界，本次未变）。
