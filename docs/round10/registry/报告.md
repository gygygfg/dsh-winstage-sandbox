### 3.2 关键方法学：`reg export` **不是**字节稳定的 —— raw hash 不能当零残留证据

Phase 0 实测（间隔 2 s、同一 hive、无任何探针运行）：

⇒ 因此本轮**不用 raw hash 作判据**，改用 **"归一化排序 + 显式豁免清单 + 变异体自证"** 三件套；

## 8. 缺陷

见 [`defects.md`](./defects.md)。摘要：

| 编号 | 级别 | 一句话 |
|---|---|---|
| **D-R1** | 高 | 共享覆盖 hive 失手即换**逐进程私有 hive**，而私有 hive 覆盖读路径 ⇒ **跨进程写后读全丢**（`shim/src/ws_t3reg.c:429-455`；79%/42%/64% 三档实测） |
| **D-R2** | 中 | 往**已存在**的键写被拒，且 WAL **既无 `SET_VALUE` 也无 `HARD_DENY`/`UNSTAGED`** ⇒ 三分类一种都不成立、不可归因 |
| **D-R3** | 中 | 新建键的 `SET_VALUE` **无法冻结进候选（values 0/16）**，候选退化成"只有 mkdir"；宿主侧警告诚实但可用性缺口真实 |
| **D-R4** | 低 | `/reg:32` 契约正确（`UNSTAGED`）但透传目标一律 `Access is denied` ⇒ 视图对照不可用；`reg import` **报失败却暂存成功 7 条** |
| **D-R5** | 信息 | Defender 隔离期 `tier=T1` 降级：写入**全拒且零残留**（降级链 fail-closed 正确，已由 Lead 修复） |
| **D-R6** | 低 | 我的探针缺陷（`%*` 误展开 / ESM / 引号截断），已修并留自证 |
| **D-R7** | 信息 | 历史遗留键仍在（只报告，未删除） |
