## 4. 顺带记录一条产品观察（非本轮结论，交 shim 维护者）

`Critical_powershell.*` 出现在**镜像暂存树里**说明：垫片把 `…\WER\…` 这类路径（含环境变量名 `%ALLUSERSPROFILE%`
未被展开的形态）**按字面**镜像到 `staged/fs/` 下；这与 `registry` 域记录的 "shim 注入下 PowerShell 被 WER 记为崩溃"
是同一现象的两种视角。建议后续在 shim 侧对"未展开的环境变量段 / 无效路径段"做归一化或直接 fail-closed，
而不是按字面落一棵不可枚举的镜像树。
